# WhatsApp Client

Простой WhatsApp-подобный клиент, разработанный на React с использованием
GREEN-API.

Приложение позволяет подключиться к WhatsApp-экземпляру GREEN-API, создать чат
по номеру телефона, отправлять текстовые сообщения и автоматически получать
входящие сообщения.

## Возможности

- подключение к инстансу GREEN-API;
- получение данных для подключения из переменных окружения;
- ручной ввод данных для подключения, если переменные окружения не заданы;
- создание чата по номеру телефона;
- отправка текстовых сообщений;
- получение входящих текстовых сообщений;
- автоматический polling очереди уведомлений GREEN-API;
- фильтрация входящих сообщений по активному чату;
- отображение времени сообщений;
- автоматическая прокрутка к последнему сообщению;
- ручная прокрутка истории сообщений;
- обработка состояний загрузки и ошибок;
- упрощенная валидация номера телефона;
- адаптивный интерфейс для desktop и мобильных устройств.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/avramenkomy/test-unit-wa.git
cd test-unit-wa
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка GREEN-API

Приложение поддерживает два способа передачи данных подключения для GREEN-API.

#### Вариант 1 — переменные окружения

Создайте файл `.env` в корне проекта:

```env
VITE_GREEN_API_URL=https://your-api-url
VITE_GREEN_API_ID_INSTANCE='your_id_instance'
VITE_GREEN_API_TOKEN_INSTANCE='your_api_token_instance'
```

В качестве шаблона можно использовать файл `.env.example`.

Если все переменные окружения заданы, приложение автоматически использует их,
а поля для ручного ввода данных для входа не отображаются.

#### Вариант 2 — ручной ввод

Если переменные окружения не заданы, при запуске приложения отображается форма
подключения.

Необходимо указать:

- API URL;
- idInstance;
- apiTokenInstance.

После ввода данных нажмите `Connect`.

### 4. Запуск dev-сервера

```bash
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале.

## Использование

1. Подключитесь к инстансу GREEN-API.
2. Введите номер телефона получателя (используется упрощенная валидация номера
телефона).
3. Нажмите `Go Talking`.
4. Введите и отправьте сообщение.
5. Входящие сообщения активного чата будут автоматически отображаться в
интерфейсе.

## Получение входящих сообщений

Для получения сообщений используется endpoint GREEN-API `ReceiveNotification`.

После подключения приложение запускает polling очереди уведомлений.

Обработка выполняется следующим образом:

1. приложение отправляет запрос `ReceiveNotification`;
2. полученное уведомление проверяется;
3. входящее текстовое сообщение преобразуется во внутренний формат приложения;
4. если сообщение относится к активному чату, оно добавляется в историю;
5. обработанное уведомление удаляется из очереди с помощью `DeleteNotification`;
6. приложение запрашивает следующее уведомление.

Уведомления других типов также удаляются из очереди. Это предотвращает ситуацию,
когда необработанное уведомление блокирует получение следующих сообщений.

### `api`

Содержит функции для взаимодействия с GREEN-API:

- проверка состояния инстанса;
- отправка сообщения;
- получение уведомлений;
- удаление обработанных уведомлений.

### `hooks`

`useNotifications` содержит логику polling и управляет циклом получения
уведомлений.

### `components`

Содержит UI-компоненты приложения:

- форму подключения;
- форму создания чата;
- заголовок активного чата;
- список сообщений;
- поле отправки сообщения.

### `App.jsx`

Содержит основное состояние приложения и связывает между собой:

- подключение к GREEN-API;
- активный чат;
- отправку сообщений;
- получение входящих сообщений.

## Особенности реализации

В рамках тестового задания реализован один активный чат без полноценного списка диалогов WhatsApp.

Входящие сообщения фильтруются по `chatId`: сообщения активного чата отображаются в интерфейсе, а уведомления от других чатов обрабатываются и удаляются из очереди GREEN-API, но не добавляются в текущий диалог.

Credentials GREEN-API могут передаваться через `.env` только лишь для удобства
локального запуска. Так как приложение работает на клиенте, переменные Vite
попадают в клиентскую сборку и не являются безопасным хранением секретных
токенов.

Для production работу с секретными credentials следует реализовать на backend.

## Адаптивность

Интерфейс адаптирован для desktop и мобильных устройств.

На desktop используется двухколоночная структура с боковой панелью и активным чатом. На мобильных устройствах активный чат занимает весь экран, предусмотрен возврат к созданию нового чата.
